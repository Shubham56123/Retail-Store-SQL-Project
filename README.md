# Retail Store SQL Project

## Overview
This project demonstrates SQL concepts using a retail store database system.

## Tools Used
- MySQL

## Features
- Database schema creation
- Data insertion
- Joins
- Aggregations
- Subqueries
- Set operations
- Business-oriented SQL queries

## Database Tables
- Customers
- Products
- Orders
- Order Items
- Payments
- Product Reviews

## SQL Concepts Covered
- SELECT Queries
- WHERE Conditions
- GROUP BY
- ORDER BY
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- UNION

## Business Use Cases
- Sales Analysis
- Customer Insights
- Inventory Tracking
- Payment Reporting
